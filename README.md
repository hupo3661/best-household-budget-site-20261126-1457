HomeBudget is a household budget site that runs entirely from static files — no build step, no network request. It tracks a household's income and spending for the month, with a dashboard, a searchable and editable transaction ledger, per-category budgets with live progress, savings goals with a calculator, a bills list that flags what is overdue, and six months of reports with hand-drawn SVG charts. Every figure is derived from one ledger, so the totals always agree: $6,850 of income, $4,133.53 spent, $2,716.47 saved in November 2026.

## Run it

Serve `app/` with any static server, then open it in a browser:

```sh
node serve.ts
```

Then open http://localhost:8080 — the dashboard, transactions, budgets, savings, bills and reports are all reached from the top navigation, on desktop and on a phone.

Or serve it directly:

```sh
python3 -m http.server 8080 --directory app
```
